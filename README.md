# x5-gradient

Репозиторий, созданный специально для соревнования по машинному обучению от программы КНАД ФКН НИУ ВШЭ и X5 Tech.

## О проекте

В рамках соревнования команде необходимо предсказать выручку реального магазина сети и подготовить корректную посылку в формате `test.csv`.

Этот репозиторий используется как рабочее пространство команды для:

- подготовки данных;
- сборки baseline-решений;
- генерации и проверки submission-файлов;
- организации экспериментов для последующих этапов соревнования.

## Результат

`23.04.2026` команда прошла во второй этап уже в первый день соревнования с результатом **95.86** балла.

## Что находится в папках

### `data/raw/`

Исходные файлы соревнования:

- `train.csv` — исторические данные по магазинам;
- `test.csv` — шаблон тестовой выборки для генерации прогноза.

### `src/`

Основные скрипты проекта:

- `EDA.md` — описание разведочного анализа данных, основные наблюдения, визуализации и выводы;
- `make_baseline.py` — сборка базового submission на основе последнего доступного месяца;
- `preprocessing_pipeline.py` — пайплайн предобработки данных (заполнение пропусков, генерация признаков, подготовка датасетов);
- `validate_submission.py` — проверка формата файла перед отправкой.

### `submissions/`

Итоговый файл посылки для платформы соревнования.

### `checker.py`

Простейший вспомогательный файл для быстрой проверки чтения данных и структуры таблиц.

## Минимальный рабочий цикл

1. Считать `train.csv` и `test.csv`.
2. При необходимости выполнить предобработку через `preprocessing_pipeline.py`.
3. Сгенерировать прогноз через `make_baseline.py`.
4. Проверить готовый файл через `validate_submission.py`.
5. Отправить итоговый CSV на платформу соревнования.

## Статус

Проект находится в активной разработке и используется как основа для следующих итераций:

- локальная валидация;
- feature engineering;
- обучение моделей;
- подготовка более сильных submission-решений.
